Ferns & Petals Sales Analysis Dashboard

An interactive Excel dashboard built to analyze Ferns & Petals sales data and generate business insights through data visualization.

Key Highlights:

Analysed sales trends and revenue performance.
Identified top-performing products and customer spending patterns.
Compared revenue across different occasions and cities.
Measured average order-to-delivery time.
Built an interactive dashboard using Pivot Tables, Pivot Charts, and Slicers.
Performed data cleaning and business analysis using Microsoft Excel.
