# Ferns & Petals Sales Analysis Dashboard

**Code:** `Ferns N Petals Sales Analysis.xlsx`

## Dashboard Preview

![Sales Dashboard](Final%20Dashboard%20SS.png)
---

**Goal:** To analyse the sales performance of Ferns & Petals and identify key business insights using an interactive Excel dashboard.

**Description:**  
This project focuses on analysing the Ferns & Petals sales dataset using Microsoft Excel. The dataset includes order details, product categories, customer spending, delivery dates, occasions, cities, and revenue information. The project involved data cleaning, data transformation, creating Pivot Tables and Pivot Charts, building KPIs, and designing an interactive dashboard using slicers to provide meaningful business insights.

**Skills:**  
Data Cleaning, Data Analysis, Dashboard Development, KPI Reporting, Pivot Tables, Pivot Charts, Data Visualization, Business Analysis.

**Technology:**  
Microsoft Excel, Pivot Tables, Pivot Charts, Slicers, Conditional Formatting.

**Results:**  
The dashboard provides insights into total revenue, total orders, average order spending, delivery time, monthly sales trends, top-performing products, category-wise revenue, top cities by orders, revenue by occasions, and hourly revenue patterns, enabling data-driven business decisions.
